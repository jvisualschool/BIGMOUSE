    VISUAL GUIDE

    설정 화면을 보며 따라 해 보세요.

    실제 BigMouse의 한국어 설정 화면입니다. 이미지를 누르면 크게 볼 수 있어요.

    PERMISSIONS

    필요한 기능에만 권한을 주세요.

    키 입력 표시와 확대는 서로 다른 권한을 사용합니다. 커서 강조·클릭 효과·스포트라이트에는 이 두 권한이 필요하지 않아요.

    ⓘ

    권한 이름에 ‘오디오’가 들어 있어도 BigMouse는 오디오를 캡처하지 않습니다. 확대 화면과 키 입력을 파일에 저장하거나 전송하지 않습니다.

    작동하지 않나요?

      관리자 인증은 macOS 창에서 직접 진행하세요. 암호를 채팅이나 문의 글로 보내지 마세요.

        FIRST LAUNCH

        ‘BigMouse.app’을 열지 않음 경고가 보이나요?

        BigMouse 0.8은 업데이트 간 앱 식별을 유지하는 전용 인증서로 서명합니다. Developer ID 서명과 Apple 공증은 아직 없습니다.

        이 경고는 Apple이 앱에 악성 코드가 없는지 확인하지 못했다는 뜻이며, 악성 코드가 발견되었다는 판정과는 다릅니다.

        공식 홈페이지 또는 GitHub에서 받은 파일의 출처를 확인한 뒤, 직접 실행을 허용하려면 다음 순서로 진행하세요.

        1. 경고 창에서 ‘완료’를 눌러 닫으세요.
        2. 시스템 설정 → 개인정보 보호 및 보안으로 이동한 뒤, 아래쪽 보안 영역에서 BigMouse의 그래도 열기 를 선택하세요.
        3. Mac 암호 또는 Touch ID로 인증하고, 다시 나타나는 확인 창에서 ‘열기’를 선택하세요.

        ‘그래도 열기’가 보이지 않으면 BigMouse 실행을 다시 시도해 경고를 띄운 직후 확인하세요. macOS 버전에 따라 버튼 이름이나 위치가 조금 다를 수 있습니다.
