# BigMouse 0.3.6

Release preparation draft / 릴리스 준비 초안 — 2026-10-18

이 문서는 공개 이전 개발 빌드의 기록입니다. 첫 공개 버전은 [ver 0.7](v0.7.md)로 지정했습니다. / This is a pre-publication development-build record; the first public release is now planned as [ver 0.7](v0.7.md).

## 한국어

- macOS 지역이 대한민국이면 한국어, 다른 지역이면 영어로 자동 표시합니다.
- 설정·메뉴·권한 안내·접근성·키 입력 상태를 모두 번역했습니다.
- 일시 정지·잠자기·화면 재구성·종료 때 키 표시 문자열과 확대 이미지 참조를 정리합니다.
- 새 임시 폴더에서 빌드하고, 배포 파일 목록과 SHA-256 검증을 추가했습니다.

최소 배포 대상은 macOS 13이며 현재 준비된 바이너리는 Apple Silicon(arm64)용입니다. Intel 및 macOS 13 실기기 검증은 별도입니다.

**현재 서명 상태:** 로컬 실행용 임시 서명. Developer ID 서명·공증·공개 게시는 미완료입니다. 공개 전 최종 상태와 체크섬으로 이 초안을 갱신합니다.

키 입력 표시는 입력 모니터링, Fn 줌은 화면 기록 권한이 필요합니다. 임시 서명 앱을 업데이트하면 권한을 새 앱에 다시 연결해야 할 수 있습니다. 앱 코드는 키 입력이나 캡처 영상을 파일에 저장하거나 전송하지 않습니다.

## English

- Automatically uses Korean for the South Korea macOS region and English elsewhere.
- Localizes settings, menus, permission guidance, accessibility labels, and keystroke status.
- Releases rendered keystrokes and magnified-image references on pause, sleep, display changes, and shutdown.
- Builds in a fresh staging folder and adds release-file validation and SHA-256 checksums.

The minimum deployment target is macOS 13. The prepared binary is for Apple Silicon (arm64). Intel and physical macOS 13 testing remain separate.

**Current signing status:** ad hoc for local use. Developer ID signing, notarization, and public publication are not complete. Update this draft with the final signing state and checksums before publication.

Keystrokes require Input Monitoring; Fn zoom requires Screen Recording. Updating an ad hoc build may require reconnecting permissions. App code does not save or transmit keystrokes or captured images.
