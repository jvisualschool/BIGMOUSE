# BigMouse ver 0.8

**2026-10-19 · 무료 / Free · Apple Silicon (arm64) · 빌드 / Build 21**

## 한국어

- **기능별 단축키:** 확대·스포트라이트·키 표시를 각각 지정하고 기본값을 복원할 수 있습니다. 중복·시스템 예약·다른 앱이 사용 중인 일반 키 조합을 확인합니다.
- **한글 단축키 표시:** 한글 입력 상태에서도 `⌘ㅊ` 같은 조합을 `⌘C`로 표시합니다. 실제 입력은 변경하지 않습니다.
- **키 표시 필터:** ‘단축키만 / 모든 키’와 ‘특수키도 표시’를 선택합니다. 새 설치는 단축키만 표시하고 기존 설치의 모든 키 설정은 유지합니다.
- **버전과 오류 안내:** 설정 맨 아래에 버전을 표시하고 확대 권한 오류는 맨 위에서 바로 안내합니다.
- **업데이트 권한:** 전용 고정 인증서로 앱 식별을 유지합니다. 실제 빌드 20 → 21 교체 후 화면 기록·입력 모니터링 재허용 없이 확대와 키 입력 모니터가 작동했습니다.

이전 임시 서명에서 0.8로 처음 전환할 때는 두 권한을 한 번 다시 허용해야 합니다. 이후 앱을 종료하고 같은 위치의 앱을 새 버전으로 교체하세요. 이 Mac에서 권한 유지 검사를 완료했으며 다른 Mac·macOS 버전의 결과까지 보장하는 것은 아닙니다.

전용 인증서는 자체 발급한 코드 서명 인증서입니다. Developer ID·Hardened Runtime·Apple 공증은 없으며 첫 실행 시 macOS의 실행 허용이 필요할 수 있습니다. 인증서를 설치하거나 시스템 신뢰 설정을 바꿀 필요는 없습니다.

## English

- **Per-feature shortcuts:** Assign zoom, spotlight and keystrokes independently, restore defaults, and detect duplicates, system reservations and occupied regular key combinations.
- **Korean shortcut labels:** Show `⌘C` even when Korean input produces `⌘ㅊ`, without changing actual input.
- **Key filters:** Choose Shortcuts only or All keys and optionally include special keys. New installs default to shortcuts; existing all-key behavior is preserved.
- **Version and error visibility:** Settings shows the version at the bottom and zoom permission failures at the top.
- **Update permissions:** A dedicated, pinned certificate keeps the app identity stable. An actual build 20 → 21 replacement retained screen frames and the input monitor without re-granting either permission.

The first move from an older ad hoc build to 0.8 requires one new grant for Screen Recording and Input Monitoring. For later updates, quit BigMouse and replace it in the same location. Permission continuity was tested on this Mac; other Macs and OS versions require separate validation.

The dedicated code-signing certificate is self-issued. This release has no Developer ID signing, Hardened Runtime or Apple notarization, so macOS may require first-launch approval. Users do not need to install a certificate or change trust settings.
