## 한국어

BigMouse는 마우스 위치·클릭·키 입력을 화면에 보여 주는 무료 macOS 발표 도구입니다. 첫 공식 버전 **ver 0.7**을 무료로 제공합니다. App Store 배포, 회원 가입, 구독이나 유료 기능 해제가 없습니다.

**이 앱에는 임시 서명(ad hoc)만 있습니다. Developer ID 서명·Hardened Runtime·Apple 공증은 없으며, macOS가 첫 실행을 차단할 수 있습니다.** 별도 Mac 신규 설치, Intel, macOS 13 실기기, 외부 모니터와 화면 공유 검증은 완료하지 않았습니다.

### 다운로드와 설치

1. 아래 Assets에서 **`BigMouse-0.7-macos-arm64.zip`**과 `.sha256`을 받습니다. `source.zip`은 직접 빌드할 사람을 위한 소스입니다.
2. ZIP의 체크섬을 확인한 다음 압축을 풀고 `BigMouse.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 공식 파일임을 확인하고 앱을 실행하려는 경우, 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱을 확인합니다. [Apple 안내](https://support.apple.com/ko-kr/102445)
4. 메뉴 막대의 흰색 BigMouse 아이콘에서 설정을 엽니다. 키 표시에는 **입력 모니터링**, Fn 확대에는 **화면 기록** 권한이 필요합니다.

“컴퓨터를 손상시킵니다” 또는 “손상되었습니다”처럼 다른 경고가 나오면 실행을 중단하고 경고 문구·버전을 제보해 주세요. 설치·권한 복구 방법은 [한국어 README](https://github.com/jvisualschool/BIGMOUSE/blob/main/README.md)와 [이미지 사용 가이드](https://jvibeschool.org/BIGMOUSE/)에 있습니다.

### 주요 기능

- 7가지 커서 색상, 원 크기·테두리·채우기 조절과 클릭 반짝임.
- Control을 누르는 동안 스포트라이트, Fn을 누르는 동안 1.5–4배 돋보기.
- Option 두 번으로 키 입력 표시, 폰트·18–128pt 크기·연속/분리·위치 조절.
- macOS 지역이 대한민국이면 한국어, 그 밖에는 영어.
- 흰색 메뉴 막대 아이콘과 설정 자동 저장. 키 입력·확대 화면을 앱에서 저장하거나 전송하지 않으며 오디오를 캡처하지 않습니다.

## English

BigMouse makes your pointer, clicks, and keystrokes visible during presentations. **Ver 0.7 / build 15** is the first free official release for Apple Silicon. It targets macOS 13 or later, with no App Store installation, account, subscription, or paid feature unlock.

**This build is ad hoc signed only: no Developer ID identity, Hardened Runtime, or Apple notarization. macOS may block its first launch.** Fresh installation on another Mac, Intel support, physical macOS 13, external monitors, and screen-sharing behavior remain unverified.

Download **`BigMouse-0.7-macos-arm64.zip`** and its `.sha256` file from Assets, verify the checksum, extract, and move `BigMouse.app` to Applications. Source ZIPs are for local builds. If you trust the verified official file and choose to run this app, first try opening it, then review its entry in **System Settings → Privacy & Security → Open Anyway**. See [Apple’s instructions](https://support.apple.com/en-us/102445). Stop and report unexpected damaged-app or malware warnings.

Open settings from the white menu bar icon. Keystrokes need **Input Monitoring**; Fn zoom needs **Screen Recording**. See the [English manual](https://github.com/jvisualschool/BIGMOUSE/blob/main/README.en.md) and [visual guide](https://jvibeschool.org/BIGMOUSE/).

Features include adjustable cursor highlights and click sparkles, a Control-held spotlight, a Fn-held 1.5–4× magnifier, and Option double-tap keystroke display with customizable font, size, layout and position. Korean is selected for the South Korea macOS region; English elsewhere. Settings stay local. The app does not save or transmit keystrokes or screen frames and does not capture audio.
