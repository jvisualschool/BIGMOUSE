# BigMouse

[한국어](README.md) · [English](README.en.md)

<img src="Resources/AppIcon.png" width="96" alt="BigMouse 아이콘">

<a id="quick-start"></a>
## 빠른 시작

설치를 마쳤다면 다음 순서로 확인하세요.

1. **BigMouse를 실행**하고 화면 상단 메뉴 막대의 흰색 BigMouse 아이콘을 찾습니다.
2. **설정… → 사용**을 켭니다. 마우스를 움직여 강조 원이 보이는지 확인합니다.
3. **Control을 누른 채** 마우스를 움직여 스포트라이트를 확인합니다.
4. 키 표시를 쓰려면 **입력 모니터링 권한**을 허용하고, **Option을 짧게 두 번** 누릅니다. 안전한 연습용 입력란에서 `A`, `⌘C` 같은 키를 눌러 확인합니다.
5. 돋보기를 쓰려면 **화면 기록 권한**을 허용하고, **Fn을 누른 채** 마우스를 움직입니다.
6. 설정 창을 닫고 발표를 시작합니다. 모든 효과를 잠시 숨기려면 메뉴 막대에서 **일시 정지**를 선택합니다.

키 표시는 실행할 때마다 꺼진 상태로 시작합니다. 사용할 때 직접 켜 주세요.

<a id="installation"></a>
## 설치 방법

### 1. Mac과 배포 파일 확인

**Apple 메뉴 → 이 Mac에 관하여**에서 칩과 macOS 버전을 확인합니다.

- **Apple Silicon(M1·M2·M3 등):** `macos-arm64.zip` 대상입니다.
- **Intel:** arm64 실행 파일의 대상이 아닙니다. Intel용 배포·검증은 아직 완료하지 않았습니다.
- **Windows·Linux·iPadOS:** 현재 지원하지 않습니다.

### 2. 다운로드

[v0.7 테스트 릴리스](https://github.com/jvisualschool/BIGMOUSE/releases/tag/v0.7)에서 받습니다. [BigMouse 홈페이지](https://jvibeschool.org/BIGMOUSE/#download)도 같은 GitHub 앱 ZIP과 체크섬으로 연결됩니다.

| ver 0.7 배포 파일 | 용도 |
| --- | --- |
| `BigMouse-0.7-macos-arm64.zip` | 설치할 앱 |
| `BigMouse-0.7-macos-arm64.zip.sha256` | 앱 ZIP 무결성 확인용 |
| `BigMouse-0.7-source.zip` | 직접 빌드할 사람을 위한 소스 코드 |
| `BigMouse-0.7-source.zip.sha256` | 소스 ZIP 무결성 확인용 |

일반 사용자는 **앱 ZIP**을 선택하면 됩니다. GitHub가 자동으로 표시하는 `Source code (zip)`은 실행할 앱이 들어 있는 설치 파일과 다릅니다. 이후 버전에서는 파일명의 번호가 달라집니다.

### 3. 설치하고 실행

1. 다운로드한 앱 ZIP을 더블 클릭해 압축을 풉니다.
2. `BigMouse.app`을 **응용 프로그램** 폴더로 옮깁니다.
3. 응용 프로그램 폴더의 BigMouse를 실행합니다.
4. 첫 실행에서 설정 창이 열리면 **사용**이 켜져 있는지 확인합니다.
5. 사용할 기능에 따라 아래의 권한을 허용합니다.

앱을 한 위치에 두고 사용하세요. 다운로드 폴더·응용 프로그램·개발 폴더에 있는 여러 복사본을 번갈아 실행하면 실제 실행 앱과 권한을 등록한 앱이 달라질 수 있습니다.

### 4. 다운로드 무결성 확인

터미널에서 앱 ZIP과 `.sha256` 파일이 있는 폴더로 이동한 뒤 실행합니다.

```sh
# 두 파일을 기본 다운로드 폴더에 받았다면
cd ~/Downloads
shasum -a 256 -c BigMouse-0.7-macos-arm64.zip.sha256
```

결과가 `BigMouse-0.7-macos-arm64.zip: OK`이면 제공된 체크섬과 일치합니다. 일치하지 않으면 실행하지 말고 공식 배포 경로에서 다시 받으세요. 체크섬은 파일이 같은지 확인하는 수단이므로 ZIP과 체크섬 모두 공식 경로에서 받아야 합니다.

### macOS가 실행을 차단하는 경우

이 테스트 버전은 미공증 앱이므로 macOS가 실행을 차단할 수 있습니다. 공식 릴리스에서 받은 파일과 체크섬을 확인하고 실행하려는 경우, 앱을 한 번 연 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**에서 해당 앱을 확인하세요. [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를 참고하세요. “컴퓨터를 손상시킵니다”나 “손상되었습니다”처럼 다른 경고가 나오면 실행을 중단하고 정확한 문구와 버전을 제보하세요.

GitHub·홈페이지 직접 배포에도 **Developer ID 서명과 Apple 공증**을 사용할 수 있습니다. 이는 Mac App Store 등록 절차와 별개입니다. [Apple의 macOS 직접 배포 안내](https://developer.apple.com/macos/distribution/)

<a id="permissions"></a>
## 권한 설정

필요한 기능의 권한만 허용하면 됩니다. macOS 버전에 따라 권한 항목의 이름이 조금 다릅니다.

| 기능 | 필요한 권한 | 설정 위치 |
| --- | --- | --- |
| 커서 강조·클릭 효과·스포트라이트 | 아래 두 권한 불필요 | BigMouse에서 기능 켜기 |
| 화면에 누른 키 표시 | 입력 모니터링 | 시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링 |
| Fn 돋보기 | 화면 기록 / 화면 및 시스템 오디오 녹음 | 시스템 설정 → 개인정보 보호 및 보안 → 해당 화면 기록 항목 |

### 키 입력 표시 허용

1. BigMouse 설정의 **키 입력 · Option 두 번** 부분을 찾습니다.
2. 권한 안내 옆의 **권한 설정…**을 누릅니다.
3. macOS **입력 모니터링**에서 BigMouse를 켭니다.
4. macOS가 인증을 요청하면 시스템 창에서 직접 인증합니다.
5. **종료 및 다시 열기**를 요청하면 완료합니다.
6. 돌아온 BigMouse에서 **사용 → 화면에 누른 키 표시**를 켜거나 Option을 짧게 두 번 누릅니다.

### 돋보기 허용

1. BigMouse 설정의 **줌 · Fn** 부분에서 **권한 설정…**을 누릅니다.
2. macOS의 화면 기록 권한 목록에서 BigMouse를 켭니다.
3. 요청에 따라 앱을 다시 실행합니다.
4. **Fn을 누르는 동안 확대**를 켜고 Fn을 누르거나 **3초 미리보기**로 확인합니다.

권한 이름에 “오디오”가 포함되어도 **BigMouse는 오디오를 캡처하지 않습니다.** 화면 프레임을 돋보기에 잠시 표시할 뿐 녹화 파일을 만들지 않습니다.

권한 스위치가 이미 켜져 있는데 동작하지 않으면 [권한 다시 연결하기](#permission-repair)를 따르세요.

<a id="usage"></a>
## 기능별 사용법

### 커서 강조

설정에서 **커서 주변에 원 표시**를 켭니다.

- **강조 색상:** 노랑·주황·초록·파랑·보라·검정·흰색 중 선택합니다.
- **원 크기:** 커서 주변 원의 지름입니다.
- **테두리 굵기:** 원의 테두리를 가늘거나 두껍게 만듭니다.
- **채우기:** 원 내부 색상의 농도입니다. 0%로 설정하면 테두리만 남습니다.
- **2초 동안 움직이지 않으면 숨기기:** 정지한 커서의 강조 원을 숨깁니다. 움직이면 다시 나타납니다. 스포트라이트가 활성화된 동안에는 원이 유지됩니다.

macOS 포인터 자체의 크기나 모양은 바꾸지 않습니다. 원 크기와 테두리는 설정 상단의 미리보기에서도 확인할 수 있습니다.

### 클릭 효과

**클릭할 때 포인터 주변 반짝임**을 켜면 마우스를 누른 위치에 짧은 별빛 효과가 나타납니다. 왼쪽·오른쪽 클릭에서 확인할 수 있으며 커서 강조 원과 별도로 켜고 끌 수 있습니다.

### 스포트라이트

**스포트라이트 사용**을 켜고 지정한 키를 누르고 있으면 커서 주변의 원형 영역을 제외한 화면이 어두워집니다. 키를 놓으면 원래 화면으로 돌아옵니다.

**누르고 있을 키**에서 다음 중 하나를 고릅니다.

| 선택 | 조작 |
| --- | --- |
| `⌃ Control` | Control만 누르기 — 기본값 |
| `⌥ Option + ⇧ Shift` | Option과 Shift를 함께 누르기 |
| `⌃ Control + ⌥ Option` | Control과 Option을 함께 누르기 |
| `⌃ Control + ⇧ Shift` | Control과 Shift를 함께 누르기 |

**밝은 영역**은 원의 크기, **주변 어둡게**는 바깥 영역의 어두운 정도입니다. **3초 미리보기**로 키를 누르지 않고 효과를 확인할 수 있습니다.

선택한 조합에 Command 등 다른 보조 키를 추가하면 스포트라이트가 켜지지 않습니다. BigMouse는 다른 앱에 전달되는 키를 막지 않으므로 사용하는 앱의 단축키와 겹치면 조합을 바꿔 주세요.

### 돋보기 확대

**Fn을 누르는 동안 확대**를 켭니다. 작은 글자·아이콘·메뉴 위로 포인터를 옮기고 **Fn을 누르고 있으면** 원형 돋보기가 나타납니다. Fn을 놓으면 사라집니다.

- **돋보기 크기:** 확대 화면을 담는 원의 지름입니다.
- **확대 배율:** 원 안의 내용을 1.5–4배로 확대합니다.
- **3초 미리보기:** 화면 기록 권한과 확대 모양을 확인합니다.

Fn은 현재 고정된 조작 키입니다. 원본 앱의 확대 배율이나 문서 크기는 바꾸지 않습니다. 여러 모니터를 사용할 때는 포인터가 있는 화면을 캡처합니다.

### 화면에 누른 키 표시

입력 모니터링을 허용한 후 다음 중 하나로 켭니다.

- **Option을 짧게 두 번** 누릅니다. 다시 두 번 누르면 꺼집니다.
- 설정의 **화면에 누른 키 표시**를 켭니다.
- 메뉴 막대의 **키 입력 · ⌥ 두 번**을 선택합니다.

켜질 때 **키 입력 켜짐**이 잠시 나타납니다. 문자·숫자·방향키와 `⌘C`, `⌘V`, `⇧⌘S` 같은 키 조합을 보여 줍니다. Shift·Command 같은 보조 키만 누른 동작은 독립된 키 상자로 표시하지 않습니다.

| 설정 | 설명 |
| --- | --- |
| 폰트 | 시스템, 시스템 고정폭 또는 이 Mac에 설치된 폰트 |
| 크기 | 18–128pt |
| 연속 | 최근 입력을 하나의 상자에 이어서 표시 |
| 분리 | 각 키 입력을 개별 상자로 표시 |
| 상·중·하 | 포인터가 있는 화면의 위·가운데·아래, 가로 방향은 중앙 정렬 |

입력 후 약 **1.8초**가 지나면 표시가 사라집니다. 최근 입력은 최대 24개까지 잠시 보관하며, 공간이 부족하면 오래된 입력부터 화면에서 제외합니다. 입력 기록을 다시 열거나 저장하는 기능은 없습니다.

앱 시작·일시 정지·잠자기·사용자 세션 전환·모니터 재구성 후에는 키 표시를 다시 켜야 합니다. 폰트·크기·표시 방식·위치 설정은 유지됩니다.

## 한국어·영어 자동 선택

BigMouse는 실행할 때 **macOS의 지역 설정**을 확인합니다.

| macOS 지역 | 앱 표시 언어 |
| --- | --- |
| 대한민국 (`KR`) | 한국어 |
| 그 밖의 모든 지역 | 영어 |
| 지역 정보를 확인할 수 없음 | 영어 |

시스템의 선호 언어와 지역은 별개입니다. 영어 macOS라도 지역이 대한민국이면 한국어로, 한국어 macOS라도 지역이 미국이면 영어로 표시합니다.

**시스템 설정 → 일반 → 언어 및 지역 → 지역**을 변경한 뒤 BigMouse를 **종료하고 다시 실행**하면 적용됩니다. 앱 안에 수동 언어 선택 메뉴는 없습니다. IP·GPS·현재 여행 위치를 조회하지 않습니다.

## 강의와 화면 공유에 활용하기

| 사용 상황 | 설정 예시 |
| --- | --- |
| 일반 화면 시연 | 커서 강조와 클릭 효과를 켜고, 강조할 때만 Control을 누릅니다. |
| 단축키 강의 | 키 표시를 분리 방식·하단으로 두고 청중이 읽기 쉬운 글자 크기로 조절합니다. |
| 작은 메뉴·글자 설명 | 포인터를 해당 위치에 두고 Fn으로 잠시 확대합니다. |
| 화면을 가리지 않는 시연 | 원 채우기를 0%로 하고 2초 정지 시 숨기기를 켭니다. |

발표 전에 실제 공유 화면에서 다음을 확인하세요.

1. 공유할 모니터에 포인터를 두고 커서·클릭 효과가 보이는지 확인합니다.
2. 키 표시 위치가 자막·발표 자료·하단 버튼을 가리지 않도록 조절합니다.
3. Control과 Fn 동작을 실제 발표 앱에서 확인합니다.
4. 민감한 정보를 입력하기 전 키 표시를 끄고, 필요한 경우 공유도 중지합니다.

BigMouse의 효과는 별도의 표시 창으로 그려집니다. **전체 화면 공유와 개별 앱 창 공유는 결과가 다를 수 있습니다.** Zoom·OBS 등에서 실제 녹화·공유 결과를 확인하세요. BigMouse 자체에는 녹화·스트리밍 기능이 없습니다.

<a id="privacy"></a>
## 개인정보와 보안

- 계정, 로그인, 분석 SDK, 서버 통신, 자동 업데이트 기능이 없습니다.
- 키 표시를 켰을 때 읽기 전용 입력 이벤트 모니터를 설치하고, 끄면 제거합니다.
- 키 입력과 확대 화면을 앱에서 파일로 저장하거나 외부로 전송하지 않습니다.
- 확대에 필요한 화면 이미지는 메모리에서 사용하며 오디오는 캡처하지 않습니다.
- 색상·크기·표시 위치 등의 설정은 macOS의 로컬 설정 저장소에 보관합니다.
- 일시 정지·잠자기·화면 재구성 시 키 표시 내용과 확대 이미지 참조를 정리합니다.
- macOS 진단 로그에는 확대 시작 시간의 숫자만 기록하며 입력 문자나 캡처 화면은 넣지 않습니다.

macOS 보안 입력을 감지하면 키 표시를 비웁니다. 모든 앱의 암호 입력란이 보안 입력을 사용하는 것은 아니므로 **비밀번호·인증 코드·개인정보 입력 전에는 키 표시를 끄세요.** 화면에 보인 내용은 다른 화면 공유·녹화 프로그램에 담길 수 있습니다.

구체적인 처리 범위와 취약점 제보 방법은 [SECURITY.md](SECURITY.md)를 참고하세요.

<a id="faq"></a>
## FAQ와 문제 해결

### 1. 정말 무료인가요? App Store에서 받아야 하나요?

무료입니다. [GitHub Releases](https://github.com/jvisualschool/BIGMOUSE/releases)와 [홈페이지](https://jvibeschool.org/BIGMOUSE/)에서 직접 배포합니다. App Store 설치, 회원 가입, 구독, 유료 기능 해제는 필요하지 않습니다. 첫 공개 버전 ver 0.7은 미공증 테스트 버전으로 제공합니다.

### 2. 실행했는데 창도 Dock 아이콘도 보이지 않아요.

메뉴 막대에서 실행되는 앱입니다. 화면 상단의 흰색 BigMouse 아이콘을 눌러 **설정…**을 선택하세요. 첫 실행 이후에는 설정 창이 자동으로 열리지 않을 수 있습니다. 응용 프로그램 폴더에서 BigMouse를 다시 열어도 설정 창을 표시할 수 있습니다.

### 3. 설정 창을 닫으면 앱도 종료되나요?

계속 실행됩니다. 완전히 끝내려면 메뉴 막대에서 **BigMouse 종료**를 선택하세요.

### 4. 모든 효과가 갑자기 안 보여요.

설정 상단의 **사용**이 켜져 있는지, 메뉴 막대에 **다시 켜기**가 표시되는지 확인하세요. 일시 정지 상태는 저장되므로 앱을 다시 실행해도 유지될 수 있습니다. 사용을 켠 뒤 필요한 기능의 개별 스위치도 확인합니다.

### 5. Option을 두 번 눌러도 키 표시가 안 켜져요.

먼저 전체 **사용**과 **입력 모니터링** 권한을 확인하세요. Option만 짧게 눌렀다 놓기를 빠르게 두 번 반복합니다. 중간에 다른 키를 누르거나 클릭하지 마세요. 설정의 **화면에 누른 키 표시**를 직접 켜서 단축키 문제인지 권한 문제인지 확인할 수도 있습니다.

<a id="permission-repair"></a>
### 6. 권한은 이미 켜져 있는데 “입력 모니터링 권한 필요”가 나와요.

업데이트하거나 로컬에서 다시 빌드한 임시 서명 앱은 기존 권한 항목과 연결이 맞지 않을 수 있습니다. 같은 이름의 다른 앱 복사본이 등록되어 있어도 비슷한 증상이 납니다.

1. 사용할 `BigMouse.app`을 한 위치에 정합니다. 일반 설치는 **응용 프로그램**, 개발 빌드는 프로젝트의 `dist/BigMouse.app`입니다.
2. 메뉴 막대에서 **BigMouse 종료**를 선택합니다.
3. **시스템 설정 → 개인정보 보호 및 보안 → 입력 모니터링**을 엽니다.
4. 기존 **BigMouse** 항목을 선택하고 **−**로 제거합니다.
5. macOS가 관리자 인증을 요청하면 시스템 창에서 직접 인증합니다.
6. **+**를 눌러 1번에서 정한 실제 `BigMouse.app`을 다시 추가하고 허용합니다.
7. macOS의 **종료 및 다시 열기** 요청을 완료하거나 앱을 직접 다시 실행합니다.
8. **사용**을 켠 뒤 **화면에 누른 키 표시**를 다시 켜고 연습용 입력으로 확인합니다.

파일 선택 창에서 앱을 찾기 어렵다면 `⌘⇧G`를 눌러 앱이 있는 폴더로 이동할 수 있습니다. 권한 스위치만 켜져 있는지 확인하는 데 그치지 말고, 실제 키가 화면에 나타나는지 확인하세요.

### 7. 잠자기나 일시 정지 후 키 표시가 꺼져요.

입력이 뜻하지 않게 노출되지 않도록 키 표시를 끕니다. 앱 시작, 잠자기, 사용자 세션 전환, 전체 일시 정지, 모니터 재구성 후에는 Option 두 번으로 다시 켜세요. 폰트·크기·위치는 저장되어 있습니다.

### 8. Fn을 눌러도 확대가 안 돼요.

**사용**, **Fn을 누르는 동안 확대**, **화면 기록 권한**을 확인합니다. **3초 미리보기**도 동작하지 않으면 권한 안내를 확인하고 재실행하세요. 권한이 이미 켜져 있다면 위 재연결 절차를 **화면 기록** 권한 항목에도 적용할 수 있습니다. 키 표시가 복구되었어도 화면 기록은 별도 권한입니다.

### 9. Fn을 누르면 이모티콘 창이나 입력 소스 전환도 실행돼요.

macOS의 Fn·지구본 키 동작과 함께 실행될 수 있습니다. **시스템 설정 → 키보드 → 지구본 키를 누를 때** 항목을 확인하세요. 항목 이름은 macOS 버전과 키보드에 따라 다를 수 있으며 BigMouse가 이 설정을 바꾸지는 않습니다. Fn을 macOS에 전달하지 않는 외장 키보드는 돋보기 동작을 별도로 확인해야 합니다.

### 10. Control을 누르면 작업 중인 앱의 기능도 실행돼요.

BigMouse는 키 입력을 다른 앱으로부터 차단하지 않습니다. 스포트라이트의 **누르고 있을 키**를 Option+Shift, Control+Option 또는 Control+Shift 중 겹치지 않는 조합으로 바꿉니다.

### 11. 한글 입력 결과가 완성된 문장과 달라요.

키 표시는 개별 키 이벤트를 보여 줍니다. 한글 IME가 조합한 최종 문장이나 문서 내용을 읽는 기능이 아니므로 입력란의 완성된 글자와 다를 수 있습니다. 라틴 문자는 대문자 형태로 표시합니다.

### 12. 긴 입력이 사라지거나 큰 글자가 미리보기에서 잘려요.

키 표시는 짧은 조작 설명용입니다. 입력을 멈춘 뒤 약 1.8초가 지나면 사라지고, 공간이 부족하면 오래된 입력을 제외합니다. 글자 크기를 줄이거나 연속·분리 방식을 바꿔 보세요. 설정 창의 좁은 미리보기와 실제 화면의 표시 폭은 다릅니다.

### 13. 여러 모니터에서는 어디에 표시되나요?

키 표시는 포인터가 있는 화면에 나타나고 돋보기도 해당 화면을 대상으로 합니다. 모니터 연결·해제 후에는 키 표시를 다시 켜세요. 전체 화면 앱과 모니터 배치에 따라 보이는 결과는 실제 환경에서 확인해야 합니다.

### 14. 화면 공유나 녹화에 효과가 안 나와요.

개별 창만 공유하면 별도의 BigMouse 표시 창이 포함되지 않을 수 있습니다. 공유 대상을 확인하고 실제 청중 화면이나 짧은 녹화로 점검하세요. 전체 화면 공유를 선택할 때는 다른 창의 민감한 정보도 함께 보이지 않는지 확인합니다.

### 15. 한국에 있는데 영어로 보여요. 언어를 직접 고를 수 있나요?

실제 위치가 아니라 **macOS 지역**으로 결정합니다. 대한민국으로 지정하고 BigMouse를 완전히 종료했다 다시 실행하세요. 앱 안의 수동 언어 선택은 현재 제공하지 않습니다.

### 16. 인터넷 없이 사용할 수 있나요? 입력 내용은 저장되나요?

인터넷 없이 사용할 수 있습니다. 키 입력과 화면 프레임은 앱에서 파일로 저장하거나 전송하지 않습니다. 사용자가 고른 설정은 이 Mac에 저장합니다. 다른 화면 녹화 프로그램이 표시 내용을 녹화하는 경우는 별개입니다.

### 17. 키 표시를 켜 둔 채 비밀번호를 입력해도 되나요?

민감한 내용을 입력하기 전에 꺼 주세요. macOS 보안 입력 감지는 모든 앱의 암호 입력란 보호를 보장하지 않습니다.

### 18. 로그인할 때 자동 실행되나요? 자동 업데이트도 있나요?

앱 자체에는 로그인 시 자동 실행 등록이나 자동 업데이트 기능이 없습니다. 업데이트는 공식 배포 경로에서 새 버전을 받아 교체합니다.

### 19. 원래 마우스 커서를 크게 바꾸거나 화면에 그림을 그릴 수 있나요?

커서 주변의 강조 효과를 표시합니다. macOS 포인터 자체의 확대·교체, 화면 필기, 클릭 자동화, 키 매크로, 녹화 파일 생성은 제공하지 않습니다.

### 20. 설정을 초기값으로 돌리는 버튼이 있나요?

현재 일괄 초기화 버튼은 없습니다. [기본값 표](#defaults)를 보며 필요한 값을 조절하세요. 앱만 다시 설치해도 저장된 설정은 남을 수 있습니다.

<a id="maintenance"></a>
## 업데이트와 삭제

### 새 버전으로 업데이트

1. GitHub Releases 또는 홈페이지에서 새 버전의 앱 ZIP과 체크섬을 받습니다.
2. 메뉴 막대에서 **BigMouse 종료**를 선택합니다.
3. 압축을 풀고 기존과 같은 위치의 `BigMouse.app`을 새 파일로 교체합니다.
4. 앱을 실행하고 커서 강조·키 표시·Fn 확대를 확인합니다.
5. 권한 안내가 다시 나오면 [권한 다시 연결하기](#permission-repair)를 따릅니다.

설정은 로컬에 별도로 저장되어 일반적인 앱 교체 후에도 유지됩니다. 업데이트 후 키 표시는 다시 켜야 합니다.

### 삭제

1. 메뉴 막대에서 **BigMouse 종료**를 선택합니다.
2. 응용 프로그램 폴더의 `BigMouse.app`을 휴지통으로 옮깁니다.
3. 필요하면 시스템 설정의 입력 모니터링·화면 기록 목록에서 BigMouse 항목을 제거합니다.

앱 파일 삭제와 로컬 설정 삭제는 별개입니다. 다시 설치할 때 이전 설정이 남아 있을 수 있습니다.

<a id="development"></a>
## 소스에서 빌드하기

일반 사용자는 배포된 앱 ZIP을 이용하면 됩니다. 직접 개발하거나 로컬 빌드하려면 macOS와 Apple Command Line Tools의 Swift가 필요합니다. 외부 패키지 관리자를 사용하지 않습니다.

### 준비 및 빌드

Command Line Tools가 없다면 다음 명령으로 설치하고 설치 창의 절차를 완료합니다.

```sh
xcode-select --install
```

소스 ZIP을 풀거나 [저장소](https://github.com/jvisualschool/BIGMOUSE/)를 내려받은 뒤, `build.sh`가 있는 프로젝트 폴더에서 실행합니다.

```sh
bash build.sh
open dist/BigMouse.app
```

`build.sh`는 실행 중인 Mac의 아키텍처로 빌드합니다. 현재 검증한 환경은 Apple Silicon이며 Universal 바이너리는 만들지 않습니다. 새 임시 폴더에서 컴파일·리소스 복사·서명을 마친 뒤 기존 결과를 교체합니다.

직접 빌드한 앱에는 임시 서명을 사용합니다. **재빌드 후 권한을 다시 연결해야 할 수 있으므로**, 실제 실행할 앱 경로를 일정하게 유지하고 키 표시·Fn 확대를 다시 확인하세요.

### 검사와 패키징

```sh
bash test.sh
codesign --verify --strict dist/BigMouse.app
bash scripts/package-release.sh
```

화면 표시 검사는 로그인된 macOS 데스크톱 세션이 필요합니다. 0.7 소스를 빌드한 뒤 패키징하면 `dist/releases/v0.7/`에 ZIP과 SHA-256 파일이 생성됩니다. 스크립트는 알 수 없는 앱 내부 파일, 심볼릭 링크, 기존 ZIP 덮어쓰기를 거부합니다. 같은 버전을 다시 묶으려면 기존 산출물을 별도 위치에 보관하세요.

서명 검증 성공은 Developer ID 서명·Apple 공증 완료를 뜻하지 않습니다. 공개 배포 절차는 [GitHub·홈페이지 배포 문서](docs/DISTRIBUTION.md)에 있습니다.

### 개발 및 커밋 규칙

- **모든 커밋 메시지는 영어로 작성합니다.** 예: `Update installation instructions and troubleshooting FAQ`.
- 화면 문구를 수정할 때는 한국어와 영어 번역을 함께 반영합니다.
- 언어 선택은 macOS 지역을 기준으로 유지합니다. 대한민국은 한국어, 그 외 지역은 영어입니다.
- 키 입력이나 캡처 화면을 파일·로그·네트워크로 출력하지 않습니다.

자세한 변경·검증 기준은 [CONTRIBUTING.md](CONTRIBUTING.md)를 참고하세요.
